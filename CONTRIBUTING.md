# Contributing to SheetNest

Thanks for helping. SheetNest is free and built in the open, and there are three ways to take part.

## Translate SheetNest

SheetNest is available in English and Spanish. A new language needs no programming: one file and one pull
request. The guide is in [Localization/README.md](Localization/README.md). To suggest a better wording without
editing any file, open an issue with the **Translation** form.

## Report a problem or suggest an idea

Open an [issue](https://github.com/ManuelMRosa/SheetNest/issues). Inside SheetNest, **Help > Send Feedback...**
opens one with your version and Windows already filled in.

## Change the code

[BUILDING.md](BUILDING.md) explains how to build and test. Keep each pull request to one change, and run both test
projects before opening it. Any text a user will see goes into `Localization/Strings.resx`, with its Spanish in
`Strings.es.resx`, instead of into the code; the
[localization guide](Localization/README.md#for-developers) shows how.
