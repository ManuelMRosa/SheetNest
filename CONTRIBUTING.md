# Contributing to SheetNest

This repository holds SheetNest's open-source code up to version 1.1.14 and no longer changes.

- **SheetNest 1.1.14 and earlier:** problems can still be reported as [issues](https://github.com/ManuelMRosa/SheetNest/issues).
- **The current SheetNest** (download at [sheetnest.io](https://sheetnest.io)): write to us at
  [sheetnest.io/support](https://sheetnest.io/support/), or use **Help > Send Feedback** inside SheetNest.
